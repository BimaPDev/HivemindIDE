## Goal
The usage notch at the top of the screen only appeared on MacBooks with a camera notch. Show a drawn ("fake") notch everywhere else that you hover to open, with the same usage panel.

## Handoff
Built, typechecked, unit-tested (9 passing in hivemindNotch.test.ts), and seen running on a Mac without a notch: main log `drawn notch 160x31 at 760,0`, and the window server lists the notch window at layer 1000, top-centered. Not yet done: looking at it and hovering it by eye (the agent shell has no screen-recording permission), and any run on Windows or Linux. Uncommitted.
Next: hover the notch on a notch-less Mac and on Windows; check that on Windows `focusable: false` still lets the panel's buttons take clicks, and that the panel does not take focus from the app in front.

## Log
### 2026-10-01 05:17 · Niraj Dhakal
Asked for a fake notch, opened by hover, for a Mac without a notch and for Windows. The user chose: top center of the screen over every app (not inside the editor); the same look at rest (notch plus ears); the main display; and only when no screen has a real notch.
- `virtualNotch(display, fitMenuBar)` in common/hivemindNotch.ts: 160 pt wide, top center of the primary display. On macOS it is as tall as the menu bar (workArea.y − bounds.y, used when 22–40), else 28. `INotchRect.virtual` marks it.
- HivemindNotchMainService: dropped the macOS-only early return. `detect()` runs the osascript probe on macOS only and falls back to the drawn notch. The window is `type: 'panel'` on macOS only, and `focusable: false` on Windows (it must not take focus from the app in front). The page and the springs are unchanged.
- The Mac tab off macOS: titled "System"; memory from os.totalmem − freemem; no battery; ports through `lsof` on Linux, none on Windows (the page says "Listening ports are not listed on this system" rather than "Nothing is listening"). "On this Mac" and "the Mac may sleep" become "this computer" off macOS.
- The workbench creates MacbookNotchBridge on every platform (the class name is kept). The setting key `hivemindide.usageNotch.useMacbookNotch` is unchanged, so existing choices carry over; it is relabelled "Notch at the top of the screen" in both settings surfaces and the configuration description.
- Linux: `setIgnoreMouseEvents` cannot forward moves there, but the page already hit-tests the ~30 Hz cursor samples from main, so hover still opens it.
Demo instance gotcha: `--user-data-dir` under the long scratchpad path makes the IPC socket path longer than 103 chars and startup fails; use a short dir such as /tmp/hmn-demo/p.
